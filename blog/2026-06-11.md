# 2026-06-11

During the development of the `OpenXR` demo I had to switch to a Windows machine, because of the absence of a VR Runtime.
During the switch, some untested, platform specific code had to be adjusted to make the project compile, especially
in the CMake configurations. Some rust dependemcies had to be explicitly linked:

```cmake
if(WIN32)
    target_link_libraries(${TARGET_NAME} PRIVATE
        ws2_32
        userenv
        bcrypt
        ntdll
    )
endif()
```

Moreover, on Windows when minimizing a window the application crashes because it cannot retrieve a surface anymore.
This is not really a problem for VR, but if we want to render on-desktop images, it should be solved by pausing the
render loop when minimizing.

# 2026-06-13

After some research on ways to bridge OpenXR with WebGPU, and some discussion with the Relator, it emerged that we
have to "pull-out" some handles from the WebGPU API, that refer to the underlying components interfacing with Vulkan.

A giant problem emerges: as of recent, WebGPU native has stripped all the C++ references to these handles and seal them
in the rust code, except for `Metal`.

To solve this, the only feasible solution is to perform a *Rust FFI Injection*, which consists of tampering with the
source code of the `wgpu-native` API to expose those pointers, and then recompile the shared library file.

The `.as_hal()` method of the Rust WebGPU API allows to extract the underlaying API handles.

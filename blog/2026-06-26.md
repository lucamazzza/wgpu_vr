# 2026-06-26

While testing the new implementation of the injected functions, I found out that when using `SteamVR`, the runtime needs
to be in version `1.0`, given that it's environment is stuck at that version and strictly requires it, otherwise it
crashes.

Therefore, the version must be set in this way:

```cpp
// xrInstanceInfo.applicationInfo.apiVersion = XR_CURRENT_API_VERSION; // BEFORE
xrInstanceInfo.applicationInfo.apiVersion = XR_MAKE_VERSION(1, 0, 0);  // AFTER
```

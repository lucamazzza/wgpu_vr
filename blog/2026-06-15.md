# 2026-06-15

As stated in the last blog, to bridge the APIs of WebGPU and OpenXR I need to Engine Hack the Rust WebGPU codebase.

Here is what the additions should look like, to file [`src/lib.rs`](https://github.com/gfx-rs/wgpu-native/blob/trunk/src/lib.rs):

```rs
#[no_mangle]
pub unsafe extern "C" fn wgpuInstanceGetVulkanInstance(
    instance: crate::WGPUInstance,
) -> *mut std::ffi::c_void {
    let global = crate::api::global();
    global.instance_as_hal::<Vulkan, _, _>(instance, |hal_inst| {
        if let Some(inst) = hal_inst {
            inst.shared_instance().raw_instance() as *mut _ as *mut std::ffi::c_void
        } else {
            std::ptr::null_mut()
        }
    }).unwrap_or(std::ptr::null_mut())
}

#[no_mangle]
pub unsafe extern "C" fn wgpuAdapterGetVulkanPhysical(
    adapter: crate::WGPUAdapter,
) -> *mut std::ffi::c_void {
    let global = crate::api::global();
    global.adapter_as_hal::<Vulkan, _, _>(adapter, |hal_adapt| {
        if let Some(adapt) = hal_adapt {
            adapt.raw_physical_device() as *mut _ as *mut std::ffi::c_void
        } else {
            std::ptr::null_mut()
        }
    }).unwrap_or(std::ptr::null_mut())
}

#[no_mangle]
pub unsafe extern "C" fn wgpuAdapterGetVulkanDevice(
    adapter: crate::WGPUDevice,
) -> *mut std::ffi::c_void {
    let global = crate::api::global();
    global.device_as_hal::<Vulkan, _, _>(adapter, |hal_dev|{
        if let Some(dev) = hal_dev {
            dev.raw_device() as *mut _ as *mut std::ffi::c_void
        } else {
            std::ptr::null_mut()
        }
    }).unwrap_or(std::ptr::null_mut())
}
```

After that we need to recompile the API with the command:

```bash
cargo build --release
```

and modify the [`wgpu.h`](https://github.com/lucamazzza/wgpu_vr/blob/main/src/external/wgpu/include/wgpu.h)
to add the new functions:

```cpp
WGPU_EXPORT void *wgpuInstanceGetVulkanInstance(WGPUInstance instance);
WGPU_EXPORT void *wgpuAdapterGetVulkanPhysicalDevice(WGPUAdapter adapter);
WGPU_EXPORT void *wgpuDeviceGetVulkanDevice(WGPUDevice device);
```

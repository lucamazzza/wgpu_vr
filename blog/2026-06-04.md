# 2026-06-03

During the development of the WebGPU solution, a limitation of the API has risen, especially for macOS:
The API uses Metal directly to show frames on the screen, and when using a window the FPS has an hard limit to double
the refresh rate of the monitor, to always try to avoid tearing. This limit is not overcomeable for desktop use, but
should be no problem for VR, given that we don't use a window anymore but "print directly" to the HMD screens.
